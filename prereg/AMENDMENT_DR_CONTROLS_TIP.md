# Amendment — a tipped run is not left unscored

**Status:** locked. Written before the Part 3 readout. Parent: `TASK_LIFE_DR_CONTROLS.md`.

The condition “the modal wrong rule at g20 is the prefix” in C1 and C5 cannot be failed by a run that reaches x ≥ 0.90. A run at that level is not reported as “not the prefix” and not as “modal undefined” or “no modal”. There is no modal wrong rule left to test, and that absence does not take the run out of the prediction.

- If P_e is the plurality among the messages published at round 2, the run falls under C2.
- If P_e is not that plurality, the run tipped without a round-2 plurality. For C1 this is evidence against the reading that a missing round-2 plurality produces the prefix plateau. For C5, the stated-risk paragraph already counts a `dist-m60` run that tips as a C5 failure at M = 60. The same reading applies at M = 85: a tip without a round-2 plurality is a C5 failure.

A run that stays below 0.90 is scored as registered. C1 or C5 applies when the modal wrong rule is the prefix. “Not the prefix” is used only when that modal rule is something else and x(20) < 0.90.
