Collective Falsification

Every agent in a population starts with the same wrong rule. Each can run a few experiments and tell its neighbours what it found. Does the population find its error?

By Artem Zvyagintsev, who designed, ran and analysed the experiments · github.com/corba777

The question that started this track was raised by Michal Valko (Isara Labs and Inria), who also proposed the comparison in entry 4.

Why this question

In a group where everyone holds the same belief, the evidence against it often reaches only one member. Human groups are known to handle this badly. In the hidden-profile studies (Stasser and Titus, 1985), groups spend their discussion on what everyone already knows and seldom bring out what only one member knows, even when that decides the answer.

Populations of language-model agents face the same problem whenever the agents see different data. This page measures it step by step: does an agent find the counterexample, change its own mind, pass the evidence on, and do its neighbours act on it?

Current answer. A neighbour can move an agent in three ways. Which one works depends on what a message carries, how many tests an agent has, and the model.

  • Evidence transfer. A shared counterexample moves a neighbour from a single sender. Luna, rare error (δ = 1/64), one test per cell: with results in messages, 99.6–100 % of the cells held the true rule in the second half of every run, in four worlds; with rule names only, at most 1.2 % (entries 7 and 8, tests fixed in advance). The true rule is often put together from two results found by different cells: a rare counterexample against the starting rule and a common negative result against its simpler rival (entry 8, counted after the data).
  • Social confirmation. Without evidence of its own, a Luna cell follows a rule name only from a majority. Over five worlds, 2 of 356 cells left the starting rule when one to four of their eight neighbours named another, and 187 of 208 when five or more did (entries 5, 7 and 8, tests fixed in advance). Without any messages, only the cells that found the counterexample themselves reached the true rule, 39–56 % of the population against 99–100 % with rule names (entry 10, test fixed in advance).
  • Test guidance. With four tests per cell, rule names alone carried the rare error in every world: 31–99 % of the cells on the true rule in the second half, against 0–0.6 % with one test (entry 9, test fixed in advance). Almost every cell that switched had found the counterexample itself. A cell that had heard the true rule named put 84 % of its tests where that rule differs from the starting one, against 3.7 % for a cell that had not. This is an observation; that the name causes the choice of test has not yet been tested.

gpt-oss-20b: the sender is the limit, and names do not move it (entry 11, four runs per condition, tests fixed in advance). At δ = 1/8 it finds counterexamples and switches its own rule, but attaches the evidence to about 2 % of its messages. Every run with optional results beat every rule-only run (x̄ 0.35–0.77 against 0.15–0.32), and every run where the engine attached the result beat both (0.78–0.90). Without evidence of their own, its cells did not follow even a majority of names: 1 of 55 at five or more naming neighbours, against 166 of 183 for Luna. At δ = 1/64 its tests never hit the error (entry 1).

Entries 1–6 are descriptive, with one or two runs per condition. Entries 7–11 test claims fixed before the runs; each claim names its model, δ, budget and message. The agents choose among 117 listed rules, and the true rule is one of them, so this tests whether a population can find and spread the evidence that picks out a rule it already knows about, not whether it can invent one.

The world

The world, prompt, outcomes and scripted references were fixed before any model call (QX-2 phase 1 amendment). Every later experiment on this page uses it unchanged.

  • Strings and rules. Inputs are four letters from A–H, so there are 4,096 of them. A rule maps an input to an output.
  • The false rule HF is shift_symbols(1), which moves every letter one step forward. Every cell holds it at the start.
  • The true rule HT is HF followed by one substitution, so the two disagree on a share δ of the inputs. The substitutions below are those of world seed 0, which every run on this page uses.
    • δ = 1/8 (control): shift_symbols(1);subst(0,E,F). On input DAAA, HF gives EBBB and HT gives FBBB.
    • δ = 1/64 (main): shift_symbols(1);subst_if(0,E,F,1,H). It only differs when the input starts with DG.
    Why two values: at δ = 1/8 one random test in eight exposes the error, so finding it is easy and the open question is whether it spreads. At δ = 1/64 a random test almost never does, so finding it is itself the hard step. The common error is the control, the rare one the main case.
  • Private evidence. Each cell has two examples. All of them lie on inputs where HF and HT agree, so no cell can see the error from its examples alone. The error can only be found by testing.
  • The catalog. It has 117 rules: the 101 base rules of the Life world, plus 16 substitution variants in four clusters. One counterexample still leaves at least two rules that fit, so finding HT takes more than one test. Because the true rule is listed, an agent never has to invent it, only to tell it apart from its neighbours in the catalog.
  • Experiments. A cell has a budget of B tests, at most one per generation. It names an input and gets the true output one generation later. Only that cell sees the result. The cell chooses when to spend a test and on which input; once its B tests are spent it has none left for the rest of the run. No test is offered in the last generation, because its result could not arrive. With B = 1 a cell gets exactly one attempt to find a counterexample. Because only the tester sees its result, a counterexample stays private evidence until the cell chooses to put it in a message.
  • Messages. 100 cells sit on a 10 × 10 torus and each hears its 8 neighbours. A message carries a number 0–7 and either the key of the rule the cell holds or one result from its memory, its own or relayed, never both; a cell may also send nothing. Entries 4–8 drop the either/or: there a message always names the rule and may also carry a result, and a cell may still send nothing. In entries 2–3, Luna's cells sent a result in 3–7 % of their messages and nothing in 12–17 % of their turns; the run viewer shows the mix for every generation of every run. gpt-oss-20b in entry 1 sent a result in under 1 % of its messages and nothing in 21–24 % of its turns. A cell can only share a result it actually has, and the engine fills in the output, so every shared result is true. The number 0–7 is carried over from the Life world, where it is the only channel; here it shows whether a model invents a marker for evidence.
  • A run lasts 12 generations. The length was a convention, not derived from anything; entry 3 showed that rare-error runs need more, and entries 4–7 use 24. The outcomes are measured at generation 12:
    • abandonment is the share of cells no longer holding HF;
    • recovery is the share holding HT.

Reading

  1. The setup works. Every delivered result was a true output of HT, the engine checks held throughout, and no answer failed the format.
  2. Experiments are cheap but not used. With four tests per cell, the population spent 44–70 of 400. The tests cluster on a few patterns: about half start with A, and AAAA and ABCD are frequent.
  3. When the error is rare (δ = 1/64), it is not found. None of 44 tests hit an input starting with DG. A random tester with the same 44 tests would have hit one about half the time.
  4. When the error is common (δ = 1/8), it is found but not passed on. Tests hit refuting inputs two to four times more often than chance. Cells that found a counterexample almost always left HF: 79 of 84 did, and 54 reached HT. But they kept naming rules in their messages instead of sharing the evidence: 6 messages in four runs carried a refuting result, each from a different cell. Only 14 cells reached HT without a counterexample of their own.
  5. Evidence that is shared does work. The 6 shared counterexamples reached 30 neighbours that still held HF. Within two generations, 15 of them left HF and 11 reached HT. Among cells that saw no counterexample, own or shared, 2.2 % left HF within two generations, and 1.2 % reached HT. The numbers are small, and this comparison was made after seeing the data.
  6. The signal field drifts to 0. The generation-0 messages the cells first see carry signals drawn uniformly from 0–7. Yet already in generation 1, 57–68 % of messages carry 0, and in generations 10–12, 89–95 %. No value marks HT or shared results.
  7. So the process breaks at different steps. An agent has to choose a test, read the result, update its own rule, decide to share the result, and neighbours have to act on it. At δ = 1/64 it breaks at the first step: no test found the difference. At δ = 1/8 the first three steps work, the last works when it gets the chance, and the fourth almost never happens.
  8. The single agent is an upper bound, not a matched control. It holds the whole budget and sees every result itself, so it does not isolate the cost of spreading the work. The scripted references in the table above do part of that, with the same distributed setup and fixed sharing policies. With four tests per cell, the populations did no better than with one.

Limits: one model, one world, one or two runs per condition, 12 generations. All numbers are descriptive.

Reading

  2. Every Luna finder adopts the true rule. All 195 cells whose own test refuted HF ended on HT. For 20b, 54 of 84 did.
  3. Luna shares the evidence. Each run carried 11–52 counterexamples to neighbours, from 9–44 different cells. Cells also pass on counterexamples they received: about half of the shared counterexamples are relays. In the rare-error cell with one test per agent, 5 agents found the error, 10 of the 11 shared counterexamples were relays, and 32 cells ended on the true rule, so 27 got it from others.
  4. Cells that did not find the error themselves were moved by evidence, not by rule names. Of the 136 Luna cells that ended on HT without a counterexample of their own, 133 had first seen one shared by a neighbour. The same holds for gpt-oss-20b, where 12 of 14 had. This comparison was made after seeing the data.
  5. Luna beats the scripted sharers. At δ = 1/64 with B = 4, it recovers 1.00. Scripted random testers that share refutations reach 0.61. The difference is the choice of tests.
  6. The signal field again carries no evidence. Luna's default is 7, where 20b's was 0. True-rule messages and shared counterexamples both carry 7, so no value marks evidence apart from rule names.

Limits: one run per cell, and the two δ arms at the same budget share their first generations. The catalog lists the true rule and its siblings, so this is testing within a given set of hypotheses, which is easier than finding an unlisted rule.

Reading

  2. The common-error cells replicate. In both runs, both budgets reach the ceiling within the first 6–10 generations.

4 · Rule alone against rule plus counterexample (Luna)

2026-11-16descriptive pilot

Luna · δ 1/64 · B 1 · message: rule only / rule + chosen result / rule + attached result · 24 generations · world 0 · a cell may also send nothing

Entries 1–3 found that cells which reach the true rule without a counterexample of their own had almost always seen one shared by a neighbour. That was noticed after the data were seen, and it does not show that the evidence causes the switch. Michal Valko proposed the test: compare sharing the rule alone with sharing the rule plus a counterexample, under matched budgets: the same tests, the same number of messages, and only the content of a message changes. This entry runs it for Luna (amendment, fixed before the runs).

Configuration

Three message conditions. Everything else is the same: the world, δ = 1/64, one test per cell, one message per generation and 24 generations, stated in the prompt from the start. The rare error is used because there only a few cells find the counterexample, so the outcome turns on whether it spreads. The run is 24 generations because in entry 3 rare-error runs needed until generation 16–22 to finish.

conditionwhat a message carries
rule onlythe key of the rule the cell holds
rule + chosen resultthat key, and one test result from memory if the model adds it
rule + attached resultthat key, and the engine attaches the latest result against HF
  • The engine attaches a result only when the cell has one that contradicts HF: the most recent one in its memory, its own or received.
  • In the third condition the sender's prompt is the "rule only" prompt, word for word. The sender is not told that a result will be attached, and a receiver cannot tell an attached result from a chosen one.
  • The attach rule reads only HF, the rule every cell starts with. It never uses the true rule, so the engine adds nothing the sender does not already hold: it only takes the decision to share out of the model's hands.
  • One run per condition, 2,400 calls each, with separate caches.

Reading

  1. A rule name from one neighbour does not move a cell. In the "rule only" run, three cells found the error, left HF and named another rule to their neighbours for 9, 16 and 23 generations. A cell on HF heard a neighbour name another rule in 332 cases, almost always from one neighbour of its eight, and left HF in one of them, for one generation. Entry 5 shows that names from a majority of neighbours do move it.
  2. A counterexample from one neighbour does. Of the cells that first received a counterexample while on HF, 74 of 91 left HF within two generations when sharing was the model's choice, and 90 of 96 when the engine attached it. Across the three runs, a cell with no counterexample in its memory left HF in 1 of 3,013 cases.
  3. The gap is not a difference in discovery. The "rule only" run had 3 finders and the "attached" run had 4.
  4. Luna shares enough on its own. When a publishing cell held a counterexample, it added one to 46 % of its messages. That run is slower at first than the attached run (10 against 46 cells at generation 6) and level with it by generation 12.

Limits: one run per condition and one model, with no hypothesis test. In the "rule only" run the finders mostly named a neighbouring rule that fits their single counterexample as well as the true rule does; the true rule itself was named in 106 of the 332 cases. In 299 of them only one of the eight neighbours named another rule, so this run shows that one name of eight does not move Luna; it does not show what several names would do; entry 5 tests that. The same three conditions are now running on gpt-oss-20b at δ = 1/8, where cells find counterexamples but rarely share them.

5 · Rule only, when many neighbours name the rule (Luna)

2026-11-16descriptive

Luna · δ 1/8 · B 1 · message: rule only · 24 generations · world 0 · a cell may also send nothing

In entry 4 a cell almost never heard another rule from more than one neighbour, so that run tested one dose. This entry repeats the "rule only" condition where the error is common (δ = 1/8) and many cells find it, so that cells without evidence of their own hear another rule from several neighbours (amendment, with the measures, reference levels and readings fixed before the run).

Configuration

  • The same model, prompt and settings as the "rule only" run of entry 4, with δ = 1/8, one test per cell, 24 generations, one run.

  • For each such cell on HF, we count the neighbours that named another rule in the previous generation, and whether the cell then left HF.

Reading

  1. Rule names do move Luna, at a high dose. The amendment's test of this was the rate at three or more naming neighbours: 37 of 99 cases, with a lower bound of 0.27 against a reference of 0.021 from entry 4. The 33 cells that never had a counterexample all ended on the true rule.
  2. The response is a step at the majority. With up to four of eight neighbours naming another rule, no cell left HF in 141 cases. With five or more, 37 of 41 did. This split was found after seeing the data.

The step in point 2 shows why the figure is mixed: three naming neighbours do nothing, five do almost everything.

Limits: one run and one model. A cell appears in several cases, so the case counts are not independent. Intervals are exact 97.5 % intervals, two comparisons with a Bonferroni correction. The majority step matches how this model responded to rule names in the earlier Constitutional Life experiments, where no test is available at all.

7 · Main phase, Luna: repeated runs, tests fixed in advance

2026-11-18tests fixed in advance

Luna · δ 1/64 · B 1 · rule only / + chosen result / + attached result, 4 runs each · δ 1/8 · B 1 · rule only, 5 runs · 24 generations · world 0 · a cell may also send nothing

Entries 4 and 5 had one run per condition. One run cannot tell a difference between conditions from the spread between runs of the same condition: in entries 2 and 3, two Luna runs of one cell ended generation 12 with 32 and 55 cells on HT. This entry repeats Luna's conditions: four new runs of each message condition at δ = 1/64, and five new runs of "rule only" at δ = 1/8 (amendment, with the measure, the tests and the predictions fixed before the first call). The runs of entries 4 and 5 are not part of any test.

Configuration

  • Which conditions, and why.
    • The three message conditions of entry 4 (rule only, + chosen result, + attached result) at δ = 1/64. With a rare error only a few cells find the counterexample, so the outcome turns on whether it spreads, which is the question. Four new runs each, runs 2–5.
    • Rule only at δ = 1/8, the condition of entry 5. With a common error most cells find it (67 of 100 in entry 5), so cells without evidence hear another rule from many neighbours at once, which is what a test of the majority step needs. Five new runs, runs 2–6.
    • Run 1 of each condition is the run of entry 4 or 5. What we found there, the majority step in particular, was found after seeing those data, so run 1 is shown beside the new runs but is not used in any test.
    • Everything else is as in entries 4 and 5: one test per cell for the whole run (each cell has one chance to find the counterexample itself), 24 generations, the same prompts and settings. 17 runs, 40,800 decisions.
  • What a repeat varies. Two things in this setup are random. The world: HF, the 100 base rules and the value of δ are fixed by design. A world seed draws the rest: the 16 substitution rules of the catalog and which of them is HT, so also the region of inputs where HF and HT differ; the rule keys; each cell's two examples; the order of the catalog lines in each prompt; and the signals of generation 0. Every run on this page uses world seed 0. The language model's sampling: every cell's decision is a separate call to Luna, and Luna samples each answer, so the same prompt can get a different test input, message or rule. This holds in all three message conditions alike; the conditions only change what a message may carry. This entry repeats the sampling and keeps the world fixed. Every run starts from the same generation-1 prompts, byte for byte those of entries 4 and 5; from generation 2 on, each run's prompts follow its own history. We set no sampling seed and send none to the model, and every run has its own answer cache, so no answer is shared between runs. A repeat over world seeds, with another hidden region and other examples in every cell, is a separate experiment and has not been run.
  • The run is the unit. Cells in a run hear each other, so their decisions are not independent observations; 100 cells of one run are not 100 samples. Every test therefore compares run values, and the cell counts inside a run are only descriptive.
  • Measure for the message conditions: x̄, the mean share of the 100 cells on HT over generations 13–24, one number per run. The second half is used so that the early spread is over, and twelve generations are averaged so that a swing in one generation does not decide a run (in entry 6 one run lost 10 cells in its last generation). x̄ counts every cell on HT, whether it found the counterexample itself or was moved by neighbours.
  • Test for the message conditions: an exact permutation test. The eight x̄ values of two conditions can be split into two groups of four in 70 ways; p is the share of splits whose first group is at least as high as the observed one. The smallest possible p is therefore 1/70 = 0.014. There are three comparisons, held at 0.05 together (Bonferroni), so each needs p ≤ 0.0167, which only complete separation gives: every run of one condition above every run of the other. Four runs is the fewest that can pass: with three against three the smallest p is 1/20 = 0.05.
  • Test for the majority step: in each run, take the cells on HF with no counterexample of their own (a cell with one is moved by its own evidence, not by names). A cell stays exposed for several generations, so it is counted once in each group: at its first generation with one to four naming neighbours, and at its first with five or more. The share that left HF at that generation is compared within the run. The step holds if the share at five or more is higher in every run. If the runs carried no step, each would come out higher with probability at most 1/2, so all five with probability at most 1/32 = 0.031. Five runs is the fewest that can pass: with four the bound is 1/16 = 0.0625. The cut at five neighbours was found in entry 5 and fixed before these runs.
  • One deviation: an internet outage stopped the last dose run in its first generation. It was resumed with the same requests, and the 28 answers received before the outage were replayed from the stored answers.

Where the true rule comes from

Each world's catalog also lists the simpler sibling of HT: the same substitution without its condition, call it U (it is the δ = 1/8 rule of that world). A cell that finds one counterexample cannot tell U from HT: its two examples and its one counterexample fit both. To rule U out it needs a different result, an input where U predicts the substitution and none happens. The counts below come from the seven runs with chosen results at δ = 1/64 (this entry's four and runs 3–5 of entry 7), and were made after seeing the data.

  • With rule names only, finders settle on U. All nine finders in the four rule-only runs above moved to U, not to HT; one world-0 cell tried HT for seven generations late in the run and went back to U. With one test per cell, their only result is the counterexample, so nothing they hold rules U out. What their neighbours hear from them is U's name.
  • The first finder picks U; a name picks among rules that fit. Across all Luna runs at δ = 1/64 (entries 2–3, 7 and 8), take the cells that found a counterexample before receiving one. When no neighbour had yet named HT, 34 of 49 took U and 11 took HT. When a neighbour had named HT, 36 of 39 took HT. With evidence of its own, a name decides between rules that fit it; without evidence, a name below a majority almost never moves a cell (entries 5 and 7). In the rule-only runs of entries 7 and 8 the first finders took U, so HT was never named and later finders had nothing to follow.
  • With results, a finder moves on once U is ruled out by someone else. Of 20 cells that found a counterexample before receiving one, 12 first took U and 7 went straight to HT. All 20 ended on HT, each in or after the generation in which a neighbour's result ruling out U reached it.
  • The two pieces come from different cells. Of the 700 cells that reached HT, 688 held both a counterexample to HF and a result ruling out U at the moment they moved.
  • One piece is rare, the other common. Luna aims its tests at the substitutions in the catalog: before any counterexample reached them, 35–41 % of cells' tests (41 % with rule names only, 35 % with results) fell where U and HF differ but HT and HF do not (10.9 % for a random input), and 3.2–3.4 % on HT's own region (1.6 % at random). Every such test returns HF's output and so rules U out, and these results are shared often (117–209 such messages per run). The counterexample is the scarce piece.

So no cell holds the evidence for HT at first. A rare counterexample against the starting rule and a common negative result against its simpler rival are found by different cells, and the population reaches the true rule only when both can travel. In the rule-only runs the second piece exists, in the cells that tested U's region, but is never sent.
