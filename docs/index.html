Same Weights, Three Ways to Answer

Can an agent check a rule against its own examples, and does that decide what a population of its copies spreads?

One model, gpt-6-luna, answers in a single pass, through the Decisions API, or after reasoning. In a single pass it checks a two-step rule near chance and follows a false rule it is told most of the time; after reasoning it checks almost perfectly. On a grid of 100 copies, each with too little evidence to find the rule alone, the right rule spreads only where agents can check what their neighbours tell them, by reasoning or with an external check.

When Does Local Talk Become Collective Knowledge?

No agent can identify the rule from its one example; together the examples identify it. When does the population get there, and what decides whether it does?

Agents pass only rule names. The channel is compared against silence, a single agent given a whole neighbourhood's examples is compared against the population, and each model's response to what it reads is measured outside the population and used to predict which topology it does better on. Five models; the ranking reverses between them.

Collective Falsification

A population shares one wrong rule. What does it take for it to find the error and replace it with the right rule?

Each agent can test a few inputs and message its neighbours, with or without one of its results attached. Finding a counterexample, changing one's own rule, passing the evidence on, and acting on what arrives are each measured on single agents and compared with whole populations. The question was raised by Michal Valko.
